# Swiggy Sales Dashboard

This project is a Power BI dashboard created to analyze Swiggy food delivery sales data. The dashboard shows information about revenue, orders, customers, food categories, payment methods, delivery time, and city-wise sales.

## Tools Used

* Power BI
* Excel
* Power Query
* DAX

## Dashboard

The dashboard includes the following:

* Total Revenue
* Total Customers
* Total Orders
* Average Delivery Time
* Average Customer Rating
* Monthly Revenue Trend
* Revenue by City
* Revenue by Payment Method
* Top Food Categories
* Restaurant-wise Revenue

## Filters

The dashboard has filters for:

* City
* Cuisine
* Year
* Order Status
* Restaurant

These filters can be used to view the data based on different selections.

## Key Numbers

* Total Revenue: 14.69M
* Total Customers: 13K
* Total Orders: 27K
* Average Delivery Time: 33.85
* Average Customer Rating: 4.11

## Project Objective

The main purpose of this project is to practice data cleaning, data analysis, and dashboard creation using Power BI. It also helped me understand how to present sales data using charts, KPIs, and filters.
